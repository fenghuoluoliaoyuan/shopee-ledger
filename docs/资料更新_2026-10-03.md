## 1. 泰国：从「行业媒体解读」到「政府来源」，且修正了一个结论错误 ★

**新来源**：国家税务总局 · 税收服务"一带一路" · 全球税讯 · 泰国
https://www.chinatax.gov.cn/chinatax/c102738/c5247291/content.html（2026-01-27，内容来源标注为**泰王国海关署网站**，大连市税务局编译）

政策要点：

| 项目 | 内容 |
|---|---|
| 生效日 | 2026-01-01，《2026年低价值商品进口税收实施细则》 |
| 免税门槛 | 取消 2024-07 起实施的 1500 泰铢免税；**1 泰铢及以上全部征税** |
| 关税 | 低值统一 **10% 起始税率**，按 CIF 计算；时尚服饰鞋类最高 30%、包袋配饰 20%、电器 10% |
| 增值税 | **7%**，按 CIF + 关税合计计算 |
| 最低综合税负 | **不低于 17%** |
| 征收方式 | 邮政：海关标注税额、扫码支付；快递：公司代缴后向收件人结算；**电商平台：2025-12-22 与 Lazada / Shopee / TikTok Shop / Temu / Shein 签协议，下单时直接代收** |

### ⚠️ 我上一轮的判断需要修正

上一轮我引用行业媒体（ksher）的解读，写成"新增税负可能直接吃掉全部利润"，容易被读成**卖家承担税负**。政府来源显示的真实机制是：**税负由平台在买家下单时代收**。

所以：

- 税负**不直接从卖家毛利里扣走**；
- 真实影响是**买家到手价至少上移约 17%**，压制低价商品的转化空间；
- 结论方向不变（泰国 `dropship_viability` 仍是 `degraded`），**但理由必须改**。

**已落地**：`params/market.th.json` 重写为 5 个参数（门槛 / 关税 / VAT / 最低综合税负 / 平台代收），`viability_correction` 字段记录了这次修正；快照存为 `spec/evidence/snapshots/SNAP-TH-001-th-low-value-import-tax.md`。

**仍未解决**：这是**政府二手来源**（中国政府转述泰国海关），不是泰国海关原文。所以参数仍是 E 级、数值仍放在 `unverified_claim`，任务 `VT-045` 待你取原文升级为 A。

> 顺带暴露了证据模型的一个缺口：我的 A–E 分级里没有"权威二手"这个档。现在只能靠 `source.source_tier` 字段和注释表达（泰国标了 `government_secondary`）。**建议下一轮正式引入 `source_tier` 维度**，而不是塞进备注。

## 4. M6（流量与增长）从零到有：商品卡六要素

来源：[知虾｜Shopee 搜索结果页商品卡优化：六要素提升点击率](https://shopee.mobduos.com/article/operate/33838)（2026-09-04，行业媒体 / ERP 内容营销，D–E 级）

| 要素 | 作用 | 权重 |
|---|---|---|
| **主图** | 吸引目光、传递卖点 | **>30%**，第一决定因素 |
| 价格与促销标签 | 触发购买欲 | 第二梯队 |
| 评分与销量 | 社会证明（信任） | 第三 |
| 标题 | 搜索命中 + 信息补充 | 比多数人以为的低 |
| 免运标签 | 临门一脚 + 搜索/活动页额外曝光 | 加分项 |
| 店铺标识（商城/优选卖家） | 信任背书 | 加分项 |

可量化的参考值（已落进配置）：

- **点击率行业参考 1%–3%**；<1% 说明商品卡有明显问题，>3% 属优秀；服饰类偏高、标品类偏低、新店偏低
- 六要素系统优化六周，可从 1.6% 提到 3.5%
- **A/B 测试：单变量、3–5 天窗口**（同时改多个要素等于没测）
- 诊断分层：曝光利用率（吸引力问题）→ 流量质量（匹配度问题）→ 广告 vs 自然分开看

**已落地**：`P-TW-CTR-BASELINE`、`P-TW-MAIN-IMAGE-WEIGHT`、`P-TW-AB-TEST-WINDOW`、`P-TW-AD-CPC`(E) 四个参数 + 4 条 `G8` 门禁规则（`R-GROW-001..004`）。

## 5. 免运玩法与门槛公式（台湾站）

来源：[知虾｜Shopee 台湾站免运活动怎么做（2026 版）](https://shopee.mobduos.com/article/operate/31834)（2026-08-11，行业媒体，D–E 级）

- 免运三种形式：**店铺免运券** / **平台免运活动**（有店铺评分、类目、价格门槛）/ **类目免运**
- **门槛公式：免运门槛 = 平均客单价 × 1.1–1.2**（既能凑单又不至于够不着）
- 参与免运的商品订单量通常提升 1.5–2.5 倍（D 级，未验证）
- 不参加时的替代：定价含运费、店铺满减券、组合包邮
- 复盘：每场活动后看订单量 / 客单价 / 免运成本 / 利润变化，连续 2 场不达标就调整
- **该文同样写作"台湾站 2026 佣金 14% + 交易手续费 2.5%"** —— 这是对现有 A 级参数的第三次独立印证

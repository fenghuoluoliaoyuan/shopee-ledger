# 参数采集与确认

> 一句话：**自动抓取，人工确认**。抓到的值只进「候选」，你签字之后才成为系统依据。
> 这不是保守，是必须——平台悄悄把佣金从 14% 改成 15% 时，系统的决策不能跟着悄悄变。

## 为什么必须用浏览器脚本（实测结论）

2026-10-03 用服务端抓 4 个「公开」来源，**0 成功**：

| 来源 | 结果 | 原因 |
|---|---|---|
| `shopee.cn/edu/article/26620` | 页面抓到了，内容为空 | **JS 空壳**，内容靠浏览器渲染 |
| `help.shopee.tw/…/80088` | 超时 | 与 spec 里 VT-041 记录一致 |
| `chinatax.gov.cn` | SSL 证书校验失败 | 本地 Python 缺 CA 链，浏览器有 |
| `seller.shopee.cn/*` | 需要登录态 | 本来就不给匿名访问 |

浏览器正好补上这三点：**执行 JS、带登录态、有完整证书链**。
所以两条通路并存，各有分工：

| 通路 | 适用 | 命令 |
|---|---|---|
| 服务端抓取 | 静态页、政府站（证书正常时） | `python -m shopee_ledger fetch` |
| 油猴脚本 | JS 渲染页、需登录页 | 装 `tools/shopee-capture.user.js` |

**提取规则只写在 `spec/sources.json` 里一份**，两条通路共用。改规则不用改脚本。

## 装油猴脚本

1. 浏览器装 Tampermonkey（油猴）
2. 新建脚本 → 粘贴 `tools/shopee-capture.user.js` → 保存
3. 确保本机台账在跑：`python -m shopee_ledger web`
4. 打开任意 Shopee 页面，右下角出现「台账采集」面板

面板里选参数 → 点「抓这一页」（按住 **Alt** 只发选中部分）。
结果直接显示：抓到多少、和当前值是否一致、快照存哪、下一步做什么。

脚本**只发到 127.0.0.1**，不外发；HTTPS 页面调本地 HTTP 会被浏览器的混合内容策略拦掉，
所以脚本用 `GM_xmlhttpRequest`（扩展上下文里发请求，不受该策略限制）。

## 确认流程

```bash
python -m shopee_ledger sources            # 有哪些配方、哪些要登录
python -m shopee_ledger fetch              # 抓公开来源 → 候选
python -m shopee_ledger review             # 待确认清单（变了的排最前）
python -m shopee_ledger approve --id 2 --grade A --note "已人工核对页面"
python -m shopee_ledger reject  --id 1 --reason "页面是旧版"
```

`review` 长这样：

```
#1 P-TW-COMMISSION  **变了**  当前 0.14 → 抓到 0.15   [2026-10-03T15:00:00+00:00 userscript]
     来源 https://shopee.cn/edu/article/26620
     快照 data\snapshots\SRC-TW-COMMISSION-d7376813e3af.txt
```

`approve` 写进覆盖层时会带上：来源 URL、抓取日期、快照引用、备注。
之后在 `/spec` 页的「出处」列能一路点回去。

## 三条纪律（写在代码里，不靠自觉）

1. **抓不到就报抓不到。** 提取失败返回 `value=None` 并留快照，绝不猜一个"看起来合理"的数字。
   这跟"参数缺值不许当 0"是同一条纪律。
2. **候选不等于生效。** 抓到的值进 `ParamCandidate`（pending），`approve` 之后才写 `ParamOverride`。
3. **快照必须留档。** 按内容 sha256 存档，同一内容不写第二份。`P-GOV-SNAPSHOT` 这条治理参数就是这么要求的。

## 表结构约定

- 证据表（`AuditLog` / `CostSnapshot` / `SupplierQuote` / `ParamOverride`）**只增不改**，靠数据库触发器兜底。
- `ParamCandidate` **不是**只增不改——它是流程记录（pending → approved / rejected），
  状态可流转，但每次流转都写 `AuditLog`。**证据只增不改，流程状态可流转**，这两件事要分开。

## 还没有配方的参数

`spec/sources.json` 现在只有 8 条配方，而 spec 里有 52 个参数。
其余 44 个要么还没查出 URL（见 `docs/现在就能查的清单.md`），要么是纯经验值（不可能抓）。

加配方就是往 `sources.json` 加一条：

```json
{
  "id": "SRC-TW-DTS",
  "param_id": "P-TW-DTS",
  "url": "https://seller.shopee.cn/portal/order/list",
  "access": "login",
  "review_cycle": "quarterly",
  "extract": { "kind": "regex", "expr": "出货天数[^0-9]{0,12}([0-9]+)", "group": 1, "scale": 1 }
}
```

`kind` 支持 `regex`（带 `group` / `scale`）、`json`（点号路径）、`manual`（只提示人工抄）。

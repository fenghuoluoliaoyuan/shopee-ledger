## 4. 回填长什么样（给你个模板）

抄到之后，一个参数从"待核实"变成"可用"是这样：

```json
{
  "id": "P-TW-SLS-TIERS",
  "value": { "tiers": [ { "max_g": 500, "fee_twd": 60 }, { "max_g": 1000, "fee_twd": 75 } ] },
  "evidence_level": "B",
  "state": "active",
  "gate_eligible": true,
  "source": { "url": "卖家中心/SLS运费表", "checked_at": "2026-10-XX", "recheck_status": "machine_ok", "snapshot_ref": "SNAP-TW-010-sls-tiers" },
  "review_cycle": "quarterly",
  "next_review_at": "2027-01-XX"
}
```

变化只有四处：`value` 从 null 变成真实值、`evidence_level` 从 E 升到 B、`gate_eligible` 变 true、补 `source` 与 `snapshot_ref`。**等级不是想升就升——必须有来源和快照，这是校验器会检查的。**

| 首站真的只限台湾 | 不是问题：那是**首店**限制。先用台湾站跑通，再扩站；企业执照可直接选马来 |
